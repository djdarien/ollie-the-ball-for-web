# ollie the ball for web
Adventures of Ollie The Ball: The Lost Coin Hunt was inspired by Rolie Polie Olie. The game will be simple in nature but intuitive and fun at its core. The story goes:... Ollie awoke one morning to all of his coins lost and scattered about the universe. Now he is in search of his lost coins. Help Ollie collect the coins by rolling Ollie over all coins in each level.
